# Travel Fare Calculator 
- Calcuates the amount of money for your trip.
## Version 1 – Original code without input validation
- **_INPUT_**: Accepts the name of the passenger, the distance traveled in kilometers, and the total amount of passengers riding.
- **_PROCESS_**: Multiplies the distance by PHP 14 and the number of passengers, then rounds the total fare to two decimal places.
-  **_OUTPUT_**: Displays the passenger's name and total fare in *PHP*.
